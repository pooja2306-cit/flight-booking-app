# Flight Booking App

This is a Flask-based web application for booking flights.

## Features
- User Registration & Login
- View Available Flights
- Book Flights
- View Bookings

## Technologies Used
- Python (Flask)
- SQLite
- HTML/CSS

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run the app:
   python app.py
3. Open browser:
   http://127.0.0.1:5000/
